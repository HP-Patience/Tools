# 本地 Web 抢购控制台设计

日期：2026-10-11
状态：用户已确认设计，并授权计划后直接实现，无需再次确认。

## 目标与范围

为现有 Python 抢购工具增加可实际控制任务的中文 Web 页面。沿用现有商品配置、浏览器启动、CSRF 捕获和购买算法，保留 CLI 与原 bat 入口。仅本机使用，不包含公网部署、多用户、自动付款、提高请求频率或更换活动商品。

## 架构选择

采用轻量 Python HTTP 服务 + 原生 HTML/CSS/JavaScript + 独立任务子进程。

相比 React + 独立构建链，该方案无需 Node，符合目前的小型 Python 项目；相比直接在服务进程里调用脚本，子进程更容易隔离任务、收集输出与停止。服务框架在实施计划阶段选定，优先最少依赖。

建议新增 seckill_web.py（本地服务及任务管理）、web_worker.py（非交互任务适配）、web/（静态页面）、tests/（模拟验证）以及 Web 启动 bat。

## 页面和交互

中文深色控制台，桌面双栏布局，小屏改为单栏。状态卡显示登录态、运行状态、任务类型、地域及目标时间；操作卡选择地域（上海4/北京8/广州1）和场次（最近/10:00/15:00）；日志区按顺序显示可滚动日志，支持自动跟随、暂停跟随和清空页面显示。

扫码登录打开本机可见浏览器，用户在该浏览器内扫码，而不是在控制台页面传递二维码或 Cookie。测试连通使用 get-vip-info，绝不调用购买接口。开始抢购与真实测试下单弹出独立确认框，列明商品、地域、场次及真实订单风险；取消不发送启动请求。

运行期间禁用所有启动入口及配置修改，仅允许停止。断线显示“连接中断”，不误报任务已停止；重连恢复真实任务状态和日志。停止提示已创建订单不会撤销。最终状态区分成功、失败、停止和未知结果，不将正常退出自动当作抢购成功。

## 服务接口

- GET /api/status：任务 ID、类型、状态、地域、场次、目标时间、登录校验状态和最近日志序号；不返回 Cookie 或 config 敏感字段。
- GET /api/logs?after=<seq>：有界增量日志，序号单调增长；缓存截断时提供缺口标记。页面每约1秒轮询，与状态读取合并或并行。
- POST /api/config：验证地域白名单，保存时保留现有 config 的其他键；任务运行时返回冲突。
- POST /api/tasks：action 为 login/connect/grab/test-order，region 与 session 经白名单校验。grab/test-order 必须有明确确认标志，否则拒绝；运行或停止中再次启动返回409。
- POST /api/tasks/stop：按任务 ID 停止，拒绝停止旧任务 ID，重复停止安全。

所有变更操作要求本次服务生成的随机令牌，并检查 Host/Origin，限定本地地址和当前服务端口；不启用跨域访问。静态文件仅从 web 目录白名单提供，拒绝路径穿越，不开放项目文件目录。服务默认127.0.0.1，端口占用时明确报错。

## Python 适配与任务生命周期

源码中 do_login、ensure_login、test_connect、test_order 包含 input；ensure_login 当前还会在校验异常时按有效处理。Web 路径必须提供显式非交互模式：失败关闭，校验异常阻止下单，失效登录提示先扫码，不能向 stdin 等待输入，也不能自动回答风险确认。

复用核心函数，最小增加参数或提取公用流程，维持 CLI 默认交互。Worker 使用 asyncio 执行单个任务，输出 UTF-8 无缓冲日志及结构化结果事件。购买结果从实际返回值获得，不通过日志关键词猜测。

任务状态：idle → running → stopping → stopped，或 running → succeeded/failed；购买成功仅以核心购买返回值确认。没有明确结果时为 failed/unknown，不伪装成功。目标场次按本机所在地日期计算，过去的指定场次顺延到次日；对时后目标倒计时使用校准后的时间，前端不作为精确开抢时钟。

TaskManager 用锁保护启动/停止/完成，同一时刻只有一个任务。停止先请求协作取消并进入 stopping，worker 的 finally 保存必要状态并关闭本次浏览器；限时未退出再终止本任务子进程树。不得结束其他用户浏览器。服务关闭同样清理本任务进程。日志缓存有上限，去除终端 ANSI 转义并通过 textContent 展示，防止输出注入 HTML。

.state.json 的存在仅显示“已保存，待校验”；只有真实查询通过才显示“已验证”。Cookie、CSRF、Bark key 等敏感信息不应进入前端日志。前端显示的商品及金额是项目现有配置，不表示已核实活动当前有效。

## 验证与验收

自动测试全部使用模拟 worker/浏览器/购买函数，不访问腾讯云，不创建订单。

1. 页面可加载且中文正常；默认启动不执行任何任务。
2. 地域配置保存保留其他配置键，无效地域/场次/任务类型被拒绝。
3. 缺少确认或安全令牌的购买启动被拒绝；异源请求与路径穿越被拒绝。
4. 连续点击或并发启动最多产生一个任务；旧任务结果不能覆盖新任务状态。
5. 日志增量、缓存边界、断线恢复及输出 HTML 转义正确。
6. 停止、重复停止、超时强制停止、服务关闭清理得到测试覆盖。
7. 非交互模式没有 input 等待，登录未知/失效均不能购买；connect 永不购买。
8. 浏览器用模拟任务验证设置、确认取消/确认、日志、停止以及窄屏布局。
9. 原 CLI 默认交互兼容；README 增加安装、启动、停止限制与风险说明。

真实扫码登录和真实抢购由用户自行操作；模拟通过不代表活动接口当前可用或一定能抢到。
