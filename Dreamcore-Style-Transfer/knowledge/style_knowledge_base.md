## 一、"核" (Core) 美学的文化起源

### 1.1 什么是"核"美学？

"核"美学（-core Aesthetics）是一种起源于互联网亚文化的视觉艺术流派。其核心特征是**通过对特定年代、空间或情感的极端化再现，引发观者强烈的心理共鸣**。与传统美学追求"美"不同，"核"美学追求的是"真实的心理触动"，哪怕这种触动是负面的（如恐惧、不安、忧郁）。

### 1.2 各风格的历史脉络

| 风格 | 起源时间 | 起源平台 | 文化背景 |
|------|---------|---------|----------|

## 二、各风格的深度解析（RAG 检索用）

### 2.1 梦核 (Dreamcore)

**核心心理机制**: 弗洛伊德的"怪怖"（Uncanny）——熟悉的事物变得陌生。

**视觉标志**:
- 过度曝光（Overexposure）：模拟老旧胶片相机的缺陷
- 高颗粒感（High Grain）：ISO 800+ 的胶片质感
- 柔光/Bloom效果：光线弥散，边缘柔和
- 空无一人的空间：学校走廊、游乐场、郊区住宅

**适合的图片类型**:
- 人物：女孩/儿童为主，穿校服/90年代服饰
- 场景：教育场所、游乐设施、郊区环境
- 色调：原本就偏暖的图片效果最佳
- 不适合：现代都市、科技场景

**提示词权重建议**:
- "dreamcore aesthetic" 权重 1.2
- "overexposed" 权重 0.8
- "nostalgic" 权重 1.0

### 2.2 怪核 (Weirdcore)

**核心心理机制**: 认知失调——大脑无法将图像纳入已有的认知框架。

**视觉标志**:
- 低画质：故意使用低分辨率/高压缩
- 颜色失真：色偏、通道偏移（Chromatic Aberration）
- 比例失调：物体大小违反物理常识
- 面部扭曲：五官错位、模糊化

**适合的图片类型**:
- 人物：面部特写最适合做扭曲效果
- 场景：夜间的便利店、空旷的走廊
- 色调：原本有冷暖对比的图片效果更好

**注意**: 怪核具有强烈的不安感，不适合作为"美化"滤镜。

### 2.3 阈限空间 (Liminal Space)

**核心心理机制**: "之间"（In-Between）状态——过渡空间意味着"不属于任何地方"。

**视觉标志**:
- 绝对的"无人"：不能有任何生命迹象
- 人造光源：荧光灯、应急灯
- 重复结构：无尽的走廊、相同的门
- 时间的凝固：没有任何运动迹象

**关键规则**: 阈限空间最大的禁忌是"有人"。即使是一个人影也会打破整个感觉。

### 2.4 伤核 (Traumacore)

**核心心理机制**: 解离——可爱的元素与创伤符号的并置模拟了解离体验。

**视觉标志**:
- 可爱+破碎的对比：Hello Kitty 旁边是破碎的玻璃
- 手写文字：通常是简单直白的痛苦表达
- 拼贴/Scrapbook 质感
- 褪色的粉色/蓝色调

**注意**: 伤核是创伤幸存者的表达形式，使用时应保持尊重。

### 2.5 后室 (The Backrooms)

**核心心理机制**: 对"非空间"的原始恐惧。

**视觉标志**:
- Level 0: 黄色墙壁 + 潮湿地毯 + 荧光灯（最经典）
- 无限延伸：看不到尽头
- 随机分割的房间：没有逻辑的空间布局
- 低画质"发现录像"（Found Footage）美学

**关键规则**: 后室的核心是"被困"——没有出口、没有希望。

### 2.6 童年核 (Kidcore)

**核心心理机制**: 积极的怀旧——童年的快乐被放大到超现实程度。

**视觉标志**:
- 极高饱和度：色彩几乎到达刺眼的程度
- 塑料质感：90年代的廉价玩具
- 彩虹元素：大量使用彩虹色
- 卡通贴纸覆盖

**关键情感**: 童年核是"快乐的悲伤"——知道童年回不去了。

### 2.7 池核 (Poolcore)

**核心心理机制**: 水的双重性——水既代表生命也代表死亡，空池子强化了这种矛盾。

**视觉标志**:
- 蓝白瓷砖：90年代公共泳池的标准配色
- 绝对静止的水面
- 水下光折射
- 空无一人的看台/更衣室

### 2.8 网核 (Webcore / Internetcore)

**核心心理机制**: 数码乡愁——对"更简单"的互联网时代的怀念。

**视觉标志**:
- 像素化/8-bit 元素
- Windows 95/XP UI 元素
- 闪烁 GIF / 跳舞婴儿风格
- Geocities 风格的分割线和图标

### 2.9 催眠核 (Hypnocore)

**核心心理机制**: 感官过载——视觉刺激达到导致准催眠状态的程度。

**视觉标志**:
- 螺旋/漩涡图案
- 视错觉（Moiré、Ebbinghaus）
- 万花筒效果
- 重复递归

**注意**: 使用时应加健康提示，可能引发某些人群的不适。

### 2.10 中式梦核 (Chinese Dreamcore)

**核心心理机制**: 中国千禧世代的集体记忆——电子乡愁。

**视觉标志**:
- CCD 数码相机画质（低像素、特定的色调偏移）
- 90-00年代中国特有场景：筒子楼、白瓷砖菜市场、城乡结合部
- 褪色红/暖黄/灰白色调
- 老式 CRT 电视/CCTV 的画面感

**独特关键词**:
- 电子乡愁 (electronic homesickness)
- 老式居民楼 (old residential buildings)
- 白瓷砖 (white-tiled)
- 千禧年 (millennium era China)
- 录像厅 (video rental shop)

## 四、常见问题 (FAQ)

### Q: 哪张图适合哪种风格？
- **人物照片** → 梦核 / 伤核 / 怪核
- **室内空间** → 阈限空间 / 后室 / 池核
- **城市场景** → 中式梦核 / 梦核
- **自然风景** → 梦核 / 池核
- **抽象/数字** → 网核 / 催眠核

### Q: 为什么我的提示词生成的图片不够"核"？
1. 尝试增加风格关键词的数量和权重
2. 增加负面提示词（排除现代元素）
3. 换一个 AI 模型（Midjourney v6 对"核"风格的理解比 SD 好）
4. 提高 intensity 到 "extreme"

### Q: 可以把多种"核"风格混合吗？
可以，但需要注意风格的兼容性。推荐组合：
- 梦核 + 童年核 = 温暖的儿童梦核
- 阈限空间 + 池核 = 空游泳池阈限
- 中式梦核 + 梦核 = 中国风梦核
- 不推荐：童年核 + 伤核（情感矛盾）

## 五、高级提示词技巧

### 5.1 摄影术语增强
添加摄影/电影术语可以显著提高生成质量：
- `shot on Kodak Portra 400`
- `cinematic lighting`
- `35mm lens`
- `medium format film`
- `anamorphic lens flare`

### 5.2 艺术家风格混合
可以加入艺术家的名字来引导风格：
- 梦核：`in the style of Todd Hido, Gregory Crewdson`
- 阈限空间：`in the style of Edward Hopper, Andreas Gursky`
- 怪核：`in the style of David Lynch, Francis Bacon`

### 5.3 负面提示词最佳实践
通用的"核"风格负面提示词：
```
--no realistic, polished, modern, clean, sharp focus, professional photography, 4k, high resolution, natural lighting, crowded, happy people, social media
```
