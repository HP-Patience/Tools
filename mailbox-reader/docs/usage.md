# Mailroom · 邮箱解析服务

Windows 本地邮箱凭据整理工具。Python 3.10+，前端使用 Vite 构建，构建需要 Node.js 22.12+。Python 无第三方依赖。

## 启动

双击 `start.bat` 自动构建并启动；手动启动时先执行 `npm ci`、`npm run build`，再执行：

```powershell
python app.py
```

浏览器访问 http://127.0.0.1:48371。终端按 Ctrl+C 停止服务。端口被占用或系统禁止绑定时自动换到可用端口，请以终端输出地址为准；`--open` 会打开实际端口。

## 使用

上传 `.txt`（UTF-8 或 GB18030），也可以粘贴文本，点击“解析并预览”，检查后点击“导入有效账号”。每行格式：

```text
demo@example.com----DemoPassword!----00000000-0000-4000-8000-000000000001----DEMO_TOKEN
```

界面的示例均为虚构数据，导入会成为普通账号记录。

- 最大 5 MiB、10000 行，忽略空行和文件开头的 UTF-8 BOM。
- 检查邮箱格式、Client ID 的 UUID 格式、非空密码和 Token。
- 密码不能包含分隔符 `----` 或换行；Token 内的 `----` 可以保留。密码和 Token 不去除首尾空格。
- 邮箱不区分大小写去重；同一批次保留第一条有效记录；已有记录跳过，不覆盖密码或 Token。
- 格式错误行单独显示，有效行仍可导入；导入失败时整批回滚。
- 账号库支持搜索、分页和查看凭据。导入记录展示最近 20 次操作。

## 数据保存

数据库位于 `data/mailboxes.sqlite3`，已排除 Git 跟踪。邮箱地址和导入元数据为明文；密码、Client ID、Token 由 Windows DPAPI 使用当前 Windows 用户身份加密。数据库中不保存原始导入文本。导入成功后清空输入区域；错误结果仅包含行号、邮箱和原因。

解密依赖当前 Windows 用户及其 DPAPI 环境。迁移数据库到其他用户或电脑不能保证可解密，请保留自己的原始 TXT 作为恢复来源。账号详情只在用户主动打开时返回，并在关闭窗口时清空页面内容；仍需信任运行服务的本机和当前 Windows 用户。

仅监听 127.0.0.1，固定 Host 检查、写接口会话令牌、同源检查，无外部字体或网络资源。此版本用于个人本地管理，没有多用户登录，不适合直接暴露到公网。导入时不校验 Token 的实际类型和有效期；点击“查看邮件”时验证刷新授权并读取收件箱。

## 验证

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

测试使用临时数据库和虚构凭据，不接触实际账号。

## 账号状态与归属

账号表新增固定序号（账号编号）、状态和归属。直接使用行内选项按钮修改，自动保存。

- 状态：存活（绿色闪烁圆点）、封禁（红色闪烁圆点），为手动标记，不进行邮箱存活检测。
- 归属：天选、3080、3090。新账号和旧数据默认未设置，可按需指定或清空。
- 新账号和旧数据默认状态为存活。数据库启动时自动补齐字段，不修改已有凭据。
- 状态、归属和邮箱搜索可以组合使用；支持筛选未设置归属、一键重置。分页保留筛选条件。
- 系统设置为减少动态效果时，状态圆点保持常亮。

## 排序与批量操作

账号编号默认升序（1 在上），点击“序号”表头切换降序／升序。排序作用于整个筛选结果，翻页后继续保持。

勾选账号后，在批量操作栏选择状态或归属，点击“应用到已选账号”。支持同时修改两项，也支持只修改一项；“清空归属”将所选账号设为未设置。

表头复选框全选／取消当前页；“选择全部筛选结果”会选择符合当前搜索和筛选条件的所有账号（包括其他页）。翻页和排序保留选择，搜索或筛选变化清空选择。单次最多处理 100000 个账号。批量更新使用一笔事务，任一目标不存在则整批回滚，不修改凭据。

## 鼠标拖选

在账号行的复选框、序号、邮箱地址或空白处按住鼠标左键，上下拖动即可连续选择多个账号；从已选中的行开始拖动则连续取消选择。拖动返回时，选区随鼠标位置收缩，原有其他选择保留。鼠标靠近页面顶部／底部会自动滚动，松开鼠标即停止。拖选限于当前页，跨页可继续勾选或使用“选择全部筛选结果”。

选择完成后，使用批量状态和批量归属按钮，再点击“应用到已选账号”保存。点击行内选项按钮或详情按钮不会触发拖选；复选框仍支持键盘空格操作。

## 按需查看收件箱

在账号列表点击“查看邮件”，仅请求当前账号的最近 25 封收件箱邮件；点击列表中的邮件读取正文。支持手动刷新。没有后台轮询、批量检测或自动读取其他账号。

使用当前账号的 Client ID 和刷新令牌向微软申请 Graph 访问令牌，需要该应用已获授权的邮件读取权限。访问令牌只存于服务内存；微软返回新的刷新令牌时，自动使用 DPAPI 加密更新。原密码、状态和归属保留，邮件内容不存入数据库。

正文以纯文本显示，不执行邮件 HTML、脚本，不加载跟踪图片或附件。打开和查看不会主动标记为已读。授权无效、缺少 Graph 权限、超时、限流均在窗口显示原因；遇到限流尊重等待时间，不自动重复请求。仅支持已有 Graph 授权的账号，只有 IMAP 权限或直接 Access Token 的导入数据需要重新授权。

## 邮件正文链接

正文中的 HTTP/HTTPS 网址可点击，在新标签页打开。对识别出的邮箱验证链接显示目标域名、完整网址、“打开验证链接”和“复制验证链接”按钮。复制时保留全部原始参数，不访问目标网站。

邮件内容仍以文本节点显示，不执行原邮件 HTML 或脚本；不自动打开链接。验证链接由路径和附近文字识别，无法保证目标网站仍接受该链接。

链接解析测试：`npm test`。


## Vite 开发模式

首次执行 `npm ci`，然后 `npm run dev`（或双击 `dev.bat`），访问 `http://127.0.0.1:48372`。开发脚本自动启动 Python 后端，并挑选可用的本地端口，通过 Vite 代理 `/api`；与正式服务使用同一份 `data/mailboxes.sqlite3`。

前端 CSS 支持 HMR，修改 JS / HTML 自动刷新，修改 Python 需要重启。退出时按 Ctrl+C，开发脚本同时关闭 Vite 和其启动的 Python 服务。正式服务默认使用 48371，需重新执行 `npm run build` 才会更新。

可设置 `MAILBOX_DEV_PORT` 指定 Vite 端口、`MAILBOX_DEV_BACKEND_PORT` 指定后端端口、`PYTHON` 指定 Python 可执行文件路径。仅接受本地开发地址的请求，不向网络开放。

账号列表点击邮箱地址即可复制，不触发行选择；拖选请从复选框、序号或行内空白处开始。点击「查看邮件」后自动选中第一封邮件并加载正文；空收件箱不请求正文，刷新后也默认查看最新一封。


启动及刷新默认进入邮箱账号页，状态筛选默认选择存活。状态和归属的筛选、行内编辑及批量选项全部使用直达按钮：行内点击立即保存，批量设置选好后点击“应用到已选账号”。重置筛选恢复存活和全部归属。

默认端口：日常服务 `48371`、开发前端 `48372`、开发后端 `48373`。端口被占用时自动更换，以启动输出地址为准；开发代理自动跟随后端实际端口。环境变量指定的端口也支持自动避让。


## 项目管理

默认进入「Arena项目」，升级前已有账号和状态、归属标记完整保留在这里。

点击「＋ 新建项目」创建项目。进入「全部邮箱」，单个点击邮箱的项目列，或拖选多个邮箱后点击「批量设置项目」，即可添加到指定项目。同一邮箱可以属于多个项目，重复添加不会重置已有标记。

顶部项目按钮同时用于进入项目和筛选邮箱。项目内的状态、归属、筛选和批量修改仅作用于当前项目。新加入项目的邮箱默认「存活」，归属「未设置」。「全部邮箱」用于管理项目归属，状态和归属需进入具体项目后设置。

在某个项目中导入新邮箱会自动加入当前项目；在「全部邮箱」导入则只保存到账号库。已有邮箱可直接设置项目，无需再次导入。移出项目会移除该邮箱在这个项目中的标记，邮箱凭据及其他项目的标记仍然保留。


## 登录

启用登录后首次打开页面会进入初始化界面，创建一个至少 8 位的管理员密码。之后登录凭据保存在 `data/mailboxes.sqlite3` 的哈希字段中，邮箱密码和 Token 仍由 Windows DPAPI 加密保存。

本地调试可以设置 `MAILBOX_AUTH=0` 关闭登录；正式服务默认开启登录。登录会话保存在浏览器的 HttpOnly Cookie 中，有效期为 7 天。

## 服务器部署前提

Windows 使用 DPAPI；Linux 使用 `MAILBOX_ENCRYPTION_KEY` 环境变量中的 Fernet 密钥。服务器部署应配合 HTTPS 反向代理、域名、防火墙和定期备份 `data/mailboxes.sqlite3`。不要在不同密钥之间切换，否则无法解密已有凭据。
