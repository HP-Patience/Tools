# 回环 · 浏览器视觉版

## 一键使用

- 启动：双击 `D:\Penrose-Staircase-Generator\Start-Web.cmd`。
- 网址：http://127.0.0.1:8767
- 停止：双击 `D:\Penrose-Staircase-Generator\Stop-Web.cmd`。
- 原版桌面绘图依旧可用：`Start-Penrose.cmd`。

服务只监听本机 127.0.0.1，不向局域网公开。运行时无需联网，不使用 CDN、在线字体、外部图片或 npm 依赖。
关闭浏览器标签不会停止后台服务；不使用时可以运行 Stop-Web.cmd。
重复启动会复用已有服务，不重复占用端口。如端口被其他程序占用，请查看 web\server-error.log。

## 操作

- 输入 1–10000 的整数，点击“生成”或按 Enter；左右箭头切换编号。
- 默认编号 25，构图比较均衡。默认“精选场景”包含 97 个比例较均衡的编号，箭头只在精选列表中切换。
- 切换“全部编号”可以逐一浏览 1–10000；直接输入非精选编号（例如 31）会自动切换到全部编号，不会隐藏极端构型。
- 池核 / 石膏 / 版画三套程序化材质。
- “天光”改变场景与楼梯明暗。
- 鼠标拖动或触屏拖动平移，滚轮缩放；下方 + / - / 百分比也可操作。
- 画布获得焦点后，方向键平移，+ / - 缩放，0 重置。
- 全屏按钮放大查看；Esc 退出。
- 暂停水纹可关闭动画；系统启用“减少动态效果”时默认暂停。
- “查看原理”显示二维视觉闭环。虚线不代表物理上有效的三维路径。
- “导出图像”输出 3000 × 2280 PNG 到浏览器下载目录。导出完整构图，不含页面控件；缩放和平移不影响导出，有开启的原理虚线则保留。

## 实现与限制

沿用 F. Lehr 的 pstairs.py / vpstairs.py 台阶几何与绘制顺序，原文件没有修改。
网页版保留所有踏面、台阶立面及墙体上缘；只重建四面结构墙的底边，不再直接使用原版 WH = D × 2 的墙高。
web\layout.py 根据墙体上缘求不倒置的最小墙深，按底座占地中心定位，而非按建筑整体包围框居中。底座和水池共用投影平面，底座外圈与池沿至少保留 38 个场景坐标单位的间距；不同编号的底座中心保持不变。
池沿分为后景和前景绘制，接触阴影与倒影跟随底座。不是通过裁掉越界建筑来掩盖问题。
不同构型的上缘和墙体视觉高度仍会有差异，这是保留原始错觉轮廓的结果，不等于底座不在同一投影平面。
web\geometry.py 将原绘图函数转换为多边形数据，web\server.py 提供本机 HTTP 服务，web\app.js 使用 Canvas 2D 渲染。
本项目是固定视角的二维错觉作品，不支持自由旋转或第一人称行走。
水纹、反射、光照均为艺术化程序绘制，不是物理正确的三维光追。
启动器限制编号在原项目附带数据集的 1–10000 范围内。

## 回归验证

在项目目录执行：

```powershell
& .\.venv\Scripts\python.exe -m unittest discover -s web -v
```

测试遍历全部 1–10000 号，检查底座共面、中心固定、外圈池内间距、墙面非倒置、坐标有限，以及所有原始台阶/墙体上缘在统一缩放平移后完全保留。
本次实测：10000 / 10000 通过，最小池沿间距 38.000000，最小墙体上缘到底线垂直间隙 17.799545（均为场景坐标单位）。
浏览器另外检查了精选/全部切换、31 号直接输入、前后切换、三种材质、天光、缩放、原理开关、水纹开关、390px 移动端布局，以及 3000 × 2280 PNG 的生成。数值遍历不等于逐一人工审阅一万张图。

## 房间落地关系修正

墙地交界、地砖与水池边沿现在共用一个投影方向，池台后方留出连续可见的地面。阴影以池台底面为起点，不再向下偏移制造悬浮感。这项检查独立于楼梯是否位于池内。

新增 `web\room-layout.js` 保存前端房间/池台投影参数，`web\test_room.cjs` 检查池台顶缘和落地点不跨墙、池台厚度与后端水池投影一致，并验证旧版墙地坐标确实会触发失败。

启动本地服务后，在项目目录执行 `node web/test_room.cjs` 可运行该项回归测试（需要 Node.js）。

## 编号与场景位置

空间编号不是关卡编号，而是数据集中的第 N 个彭罗斯楼梯构型。不同编号会改变四段楼梯的数量比例、台阶数量与局部轮廓，用于比较不同的视觉闭环；房间、池水和操作方式不变。

本次将完整池台组合沿房间投影方向向后移动 40 个场景坐标单位，墙地保持不动，后方仍保留 56 个单位的可见地面间隔。楼梯、底座、池水纹理、倒影和接触阴影使用同一位移，因此不会出现底座单独飞向墙面的情况。

## 单页布局

桌面端在一个视口内展示标题、场景、控制栏和状态栏，页面不再因为场景高度产生纵向滚动；窄屏/手机端仍保留正常滚动，避免控件被压缩到不可用。
