## 必须覆盖的场景

- 空地图不混入示例；示例明确标注且可返回真实地图。
- 多根布局可用；未归类内容独立；节点移动、删除快捷键和连线编辑禁用。
- 搜索隐藏节点自动展开祖先并定位；无结果反馈；搜索内容不保存或外传。
- 节点详情显示理解、疑问、来源和 AI 建议标识。
- 关系只按选中节点显示，不改变父子结构。
- 手机横向不溢出，可打开/关闭/展开详情；键盘可搜索、选节点、关闭面板。
- 格式错误、循环父子关系、悬空引用、重复 ID、危险 URL 被拒绝。
- 本地有效变更刷新，错误变更保留旧图，删除选中节点不崩溃。
- 源文件或产物被改后发布校验失败，未发布的本地修改不影响线上。
- 全站认证、HTTPS 和禁止暴露原始仓库有配置与验证说明。
