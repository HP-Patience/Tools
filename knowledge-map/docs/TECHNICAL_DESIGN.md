# 技术设计与选型决策

状态：已实现的技术基线，2026-09-10。以 MVP.md 和已确认页面草图为边界。

## 1. 技术栈

React 19 + TypeScript 7；Vite 8；React Flow 12（@xyflow/react）；Dagre 3；CSS Modules + CSS 变量；JSON Schema / Ajv；Node.js 24；npm + package-lock；Vitest 5 + Playwright；GitHub Actions + SSH；服务器使用 Caddy 或接入已有反向代理。

具体补丁版本在 package.json 和 package-lock.json 锁定。初始化通过 npm 元数据检查引擎和 peerDependencies，再以类型检查、构建、测试确认实际兼容性。

## 2. 架构

电脑 Agent → data/map.json → Schema 与图结构校验 → 本地预览 → 静态构建 release/ → 推送指定分支 → Actions 验证源文件与产物指纹 → SSH 上传独立发布目录 → 原子切换 current → Caddy HTTPS + 全站 Basic Auth → 浏览器只读查看。

无业务后端、无数据库、无线上写入、无浏览器模型密钥。Vite 插件只在本地开发时提供文件读取、监听和有效版本备份，不是线上 API。

## 3. 地图方案与验证门槛

知识文件只保存语义关系，不存画布坐标。Dagre 仅接收树的父子边，跨节点关系不参与排序；选中节点时显示相关关系。React Flow 提供画布交互，关闭节点移动、连线创建和删除。通过自定义节点实现折叠按钮。

先验证布局坐标有限且不重叠、多个根节点、折叠后的可见集合、搜索展开祖先路径；再实现界面。手机使用底部详情面板，支持面板展开与关闭，不依赖悬停。

## 4. 数据与学习边界

真实地图初始为空，examples/machine-learning.json 是显式标注的独立演示，可切换查看但不写入真实地图。节点有稳定 ID、父节点、归类位置、摘要、可选原话、知识来源、疑问、时间与内容来源类型（用户表达/材料整理/AI 建议）。跨关系也标记已确认或建议。

未归类节点单独浏览，第一版不允许未归类节点成为父节点。来源引用统一复用。所有文本按纯文本渲染，不解析不受信任 HTML；外部链接只允许 HTTP(S)。文档和完整对话不自动发布。

## 5. 状态与更新

空白态提供开始指引和独立示例入口。搜索支持标题、摘要和疑问，选择结果时展开祖先并定位。折叠、选中和缩放仅为本地浏览偏好，不写回知识文件。节点被删除后清理选择与无效折叠状态。

开发服务器监听源 JSON；校验失败通过错误横幅反馈，页面保留内存中最近的有效地图。首次无效时显示错误页。数据更新采用请求序号避免旧响应覆盖新响应；不使用 localStorage 保存私人知识。

生产数据作为带内容哈希的静态资源随页面发布；出于私人数据保护，入口与哈希资源都使用 private, no-store。旧版本目录保留，支持旧页面资源的短期兼容与回滚。线上打开/刷新才读取发布版本，不承诺跨设备同步浏览进度。

## 6. 发布完整性

本地构建前校验数据与类型。构建产物包含源输入指纹、数据指纹、构建时间和文件校验清单。release/ 随对应源码提交。Actions 在可信发布分支执行校验和测试，但不重新构建来掩盖过期本地产物；源指纹或文件哈希不一致时拒绝发布。

脚本验证部署路径与文件名；SSH 主机密钥固定；部署密钥限权。上传完整独立目录后，原子切换 current 软链接；切换前失败不影响旧版，版本标记避免较旧任务覆盖较新发布。不得先清空线上目录。

## 7. 身份验证与保密

Caddy 在文件服务之前执行 Basic Auth，保护页面、JSON、脚本与资源。使用 HTTPS、强密码和密码哈希；认证哈希仅保存在服务器配置中。GitHub Secrets 只保管部署所需私钥和主机密钥等；仓库默认私有。无自定义登录页面，不承诺可靠的应用级退出功能。

不得公开 Vite 开发端口，不得存在未认证的平行文件服务。仅部署 release/，不上传 .git、.local、AGENTS.md 或原始对话。

## 8. 暂不引入

Next.js/SSR、Express、数据库、Redux、UI 大组件库、自动生成全学科知识、多用户账号与云端 AI。采用 React 内置状态；布局适配器独立，若 Dagre 在真实大图不满足要求再评估 ELK，不提前加复杂度。

## 9. 外部上线前提

初始设计要求私有仓库、发布分支、Linux 服务器、HTTPS、服务器认证、部署账号及 Secrets。2026-09-10 实际落地使用私有仓库 HP-Patience/knowledge-map、main 分支、现有 Nginx 与受信任 IP 证书，地址为 https://121.41.92.58:18443，不要求域名或另装 Caddy。专用 zhixu-deploy 账号通过 production 环境凭据部署；首次 Actions 发布成功。Caddy 配置保留为替代部署方案，其本地测试不等同于真实 Nginx 正确密码登录验收。详见 DEPLOYMENT.md 与 ACCEPTANCE.md。

## 10. 跨平台与权限约束

源文本指纹和数据指纹统一 LF 后计算，避免 Windows 与 Linux 换行不同造成误报；发布文件按原始字节计算哈希，Git 属性对 release/** 禁用文本转换。

只读 React Flow 容器禁用编辑事件，自定义节点按钮明确启用 pointer-events，保证折叠与点击仍可用。保留 React Flow 归属信息，不隐藏需要授权的标识。

## 11. 生产 CSP 验证

Ajv Schema 在 Node 中预编译为独立校验函数，浏览器不运行 Schema 编译器，因此不需要 unsafe-eval。修改 Schema 后执行 npm run schema:generate；check/build 会拒绝过期的预编译校验器。真实 Caddy 配置加版本化产物进行认证与浏览器冒烟测试，不仅测试 Vite 开发模式。

## 12. 只读画布的测量状态

受控 React Flow 节点仍需接收 dimensions 变更。画布只在组件内保存实际宽高测量值并回传 measured，不接受位置、删除或选择变更写入知识数据。useNodesInitialized 完成后才执行定位与全图缩放。浏览器回归既验证搜索后目标居中，也验证回到全图后所有节点实际位于画布边界内，不能以按钮可点击或详情标题变化代替定位验收。

## 13. 桌面侧栏收起

左侧导航提供收起按钮，收起后顶部保留展开入口，画布通过 Grid 重新分配宽度，不清空当前地图、节点选择或折叠分支。侧栏状态只保存在当前页面；专注模式退出后恢复原侧栏状态。700px 及以下继续使用独立的移动端抽屉，桌面收起状态不阻止手机导航打开。按钮支持键盘操作与焦点交接。


## 14. 节点教材式阅读

`overview` 为顶部常显的一段话概览，`summary` 为完整教材式正文，默认收起，通过原生 details/summary 独立展开。可选的 `originalExpression` 是另一个同级、默认收起的原始表达区，不随正文折叠而隐藏入口。切换地图或节点重置展开状态。来源和疑问仍放在更多内容中，性质与状态不由文风推断。

所有文字继续按纯文本安全展示，不引入 Markdown/LaTeX 渲染依赖。移动端通过详情面板滚动阅读完整文字，不对概览或已展开正文使用三行截断；折叠状态仅在浏览器内存中，不写回数据。

## 15. 详情宽度与全屏阅读

桌面详情可沿左边缘拖动宽度，不设置固定的最小/最大阅读宽度，仅由剩余页面空间约束，左侧导航收起后可占满页面宽度。宽度保存在当前页面状态中，不写入知识数据。详情全屏按钮将面板铺满浏览器页面（不强制隐藏浏览器工具栏），桌面与手机都可用；退出按钮或 Esc 恢复原宽度、选择及正文折叠状态。全屏期间背景不可交互，键盘焦点留在详情内，顶部退出控件随滚动保持可见。

正文展示按空行分段，短的独立数字编号标题显示为章节标题，段内换行和全部原始字符保留；不解析 HTML、Markdown 或 LaTeX，不写回知识数据。阅读列居中、最长 780px，宽度不足时随窗口收缩；这只是正文行长，不限制详情窗口拖拽或全屏尺寸。正文采用深色文字与独立段落间距，不再整篇使用引用底色；全屏提高字号，顶部退出按钮保持可见。
